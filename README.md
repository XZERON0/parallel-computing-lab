# Parallel Computing Lab

Учебное исследование ускорения CPU-bound вычислений при разном числе процессов.

## Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Откройте http://localhost:8000

## Docker

```bash
docker build -t parallel-computing-lab .
docker run --rm -p 8000:8000 --cpus=2 parallel-computing-lab
```

Для сравнения ограничений CPU повторите запуск с `--cpus=1`, `--cpus=2`, `--cpus=4` (останавливая предыдущий контейнер). Ограничение CPU не гарантирует такое же число доступных логических ядер, которое возвращает `os.cpu_count()`.

## Методика

- Задача: поиск простых чисел от 2 до N включительно, пробным делением до квадратного корня.
- Один процесс: прямой последовательный вызов функции.
- Несколько процессов: `ProcessPoolExecutor`, диапазон делится на непересекающиеся участки.
- Измерение: `time.perf_counter`, медиана из 1–5 повторов.
- Проверка: число найденных простых чисел во всех режимах совпадает.
- Ускорение S(p)=T(1)/T(p); эффективность E(p)=S(p)/p*100%.

Замеры включают затраты на запуск процессов и передачу задач. При маленьком N параллельный вариант может быть медленнее. Тесты выполняются последовательно по конфигурациям, поэтому фоновые процессы и нагрев CPU могут влиять на результаты. Для отчёта укажите характеристики ПК, ОС, лимит CPU и фактические замеры.
